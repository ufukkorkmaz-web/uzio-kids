Uzio - optimized version

Open index.html in a browser. Keep index.html, styles.css, app.js and the assets folder together.

Changes: separated HTML/CSS/JS; extracted and compressed five 1920x1080 scene images as WebP; preserved layout, animation, navigation, glass styling and transitions; removed GPU-heavy custom SVG displacement filters; limited parallax updates to one animation frame and the currently visible scene; avoided painting far-off scenes; reduced oversized transition glow.

Note: the contact form in the original is a front-end demo, not a connected mailing list.
